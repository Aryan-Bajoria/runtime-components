# Runtime Components

This is a basic setup of runtime components for developers. This includes
runtime components for bash, zsh, vim, git, gdb

## Files

The following files are included in the repository:
-   .bashrc: Runtime Component read by bash
-   .zshrc: Runtime Component read by zsh
-   .vimrc: Runtime Component read by vim
-   .gitconfig: Configuration read by git
-   .gdbinit: Runtime Component read by gdb
